# Лабораторные по ML

Зависимости: `pip install -r requirements.txt`.

Пути к данным ищутся и из папки лабораторной, и из корня проекта.

## Структура

| Папка | Работа | Данные |
| --- | --- | --- |
| `lab1_text` | Классификация новостей BBC, наивный Байес | `data/bbc_news.csv` |
| `lab2_stocks` | Прогноз цены Microsoft: SARIMA и LSTM | `data/microsoft_stock.csv` |
| `lab3_fraud` | Мошенничество по картам: логистическая регрессия, Isolation Forest, One-Class SVM, автоэнкодер | `data/creditcard.zip` |
| `lab4_recommendations` | Предсказание оценки товара пользователем | `data/Reviews.csv` |

`microsoft_stock.csv` и `Reviews.csv` положите в `data/` соответствующей лабораторной. `creditcard.zip` уже лежит в `lab3_fraud/data/` и в git не попадает: архив около 70 МБ.

## Лаба 1. Тексты

Датасет BBC: текст новости и метка. Классы: politics, sport, technology, entertainment, business. Текст чистится, считаются признаки, классификатор — `GaussianNB`.

## Лаба 2. Временной ряд

Ряд цены закрытия Microsoft. Прогноз на тестовый хвост: SARIMA `(5, 2, 2) x (1, 1, 1, 12)` и LSTM.

## Лаба 3. Аномалии

Датасет [Credit Card Fraud](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud): транзакции, целевая колонка `Class` (1 — мошенничество). Сравниваются логистическая регрессия, Isolation Forest, One-Class SVM и автоэнкодер с логистической регрессией на сжатых признаках.

## Лаба 4. Рекомендации

Исходные данные — отзывы Amazon Fine Food Reviews (`UserId`, `ProductId`, `Score` и другие поля). Для обучения оставлены три поля. Выборка уменьшена: 40% строк, пользователи и товары с минимум тремя оценками. Так обучение короче по времени.

- **X:** `UserId`, `ProductId`
- **y:** `Score` — оценка пользователя этому товару

Две модели в `recommend.py`:

1. **Матричная факторизация.** Эмбеддинг пользователя и эмбеддинг товара, скалярное произведение векторов. Loss — MSE, оптимизатор Adam, 4 эпохи.
2. **Нейросетевая факторизация.** Те же эмбеддинги, dropout, скалярное произведение, полносвязный слой с ReLU, ещё dropout, выход на одно число. Loss — MAE, Adam, 5 эпох.

### Слои и обучение

- **Embedding** — таблица векторов. Id пользователя или товара заменяется вектором длины 64. Близкие по оценкам объекты получают близкие векторы.
- **Flatten** — снимает лишнюю размерность после эмбеддинга, остаётся один вектор.
- **Dot** — скалярное произведение вектора пользователя и вектора товара. Большое значение — высокая предсказанная оценка.
- **Dense** — полносвязный слой: каждый выход — взвешенная сумма входов плюс смещение.
- **ReLU** — `max(0, x)`. Отрицательные значения обнуляются, слой учит нелинейную зависимость.
- **Dropout** — на обучении случайно зануляет часть выходов (здесь 0.3 у эмбеддингов и 0.4 после Dense), чтобы модель не запоминала обучающую выборку.
- **Loss** — число: насколько предсказание расходится с верной оценкой. Меньше loss — ближе к ответам на тех данных, по которым его считают. Смотреть нужно и train, и validation: если падает только train loss, модель переобучается.
- **MSE** — среднее `(y − ŷ)²`. Крупный промах штрафуется сильнее. Loss первой модели.
- **MAE** — среднее `|y − ŷ|`. Loss второй модели. На графике второй модели по оси Y тоже MAE.
- **Adam** — оптимизатор. На каждом шаге меняет веса так, чтобы loss уменьшался, шаг подстраивается отдельно для каждого веса.
